# BRAINROT.EXE

An interactive first-person Backrooms escape experience with procedural Three.js environments, original Web Audio music, puzzles, scares, checkpoints and touch controls.

## Hosting

GitHub Pages serves the `docs/` directory on `main`. All assets are local. Serve `docs/` with any static HTTP server for local development. WebGL 2 is required.

## Controls

Enter to begin. WASD to move, arrow keys to turn, drag to look, E to interact, J for field notes, Escape to pause. Touch controls appear on phones. Volume, scare intensity and motion preferences are in the pause menu.

Progress is saved locally in the player's browser. No analytics or remote player database.

Third-party font and Three.js license files are included beside their assets.
